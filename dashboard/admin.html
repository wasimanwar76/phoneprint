Production checklist

  • • Use Supabase Auth; admin authorization comes from trusted app_metadata.role.
  • • Enable RLS on all partner tables. Do not expose KYC documents through public URLs.
  • • Create partner login users via a secure server/Edge Function using the service-role key server-side only.
  • • Use a backend Cashfree webhook to verify paid status and insert commission entries exactly once.
  • • Partner codes are referral identifiers, not passwords or authentication credentials.
